# GLOSSARY Format

Glossary entries provide a shared, unambiguous vocabulary for the project's domain.

## Template

```md
### {Term}
- **Definition**: {A concise, precise explanation of the term}
- **Context**: {How the term is used in this project, or why this specific definition was chosen}
- **Notes**: {Related terms, edge cases, or warnings}
```

## Integration Rules

1. **Alphabetical Order**: Entries must be sorted alphabetically by the term.
2. **No Synonyms**: If a term with the same meaning already exists, do not create a new entry. Instead, update the existing entry or add a "See also" reference.
3. **Deterministic Definitions**: Definitions must be objective and avoid vague language.
